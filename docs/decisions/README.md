## How to Add a Decision

Create a new file with a descriptive kebab-case name.
Use the format: `B-XX-short-name.md`.
Include:

1. Status (OPEN / RESOLVED / SUPERSEDED)
2. Decision owner
3. Question
4. Resolution (if resolved)
5. Implications (if resolved)
